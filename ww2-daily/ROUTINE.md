# Рутина Claude: ежедневный пост

Как поставить ежедневную автопубликацию в облаке (без участия компьютера).

## Создание рутины

1. Открой **claude.ai/code → Routines → New routine**.
2. **Репозиторий**: этот (`ww2-daily`).
3. **Среда**: с настроенными переменными окружения, сетевой политикой **Custom** и
   setup-скриптом `pip install -r requirements.txt` (см. README).
4. **Модель**: **Opus 4.8**, уровень рассуждений — **максимальный** (high/max).
5. **Расписание**: ежедневно. Запуск — **09:30 по Москве** (= `30 6 * * *` в UTC,
   МСК = UTC+3 без перехода на летнее время). Запас в 30 минут до 10:00 на работу рутины.
6. Вставь **промпт рутины** (ниже) и сохрани. Сначала прогони кнопкой **Run now** и
   проверь результат, потом полагайся на расписание.

## Промпт рутины (вставить в поле задачи)

```
Ты публикуешь ежедневный пост канала «Дневник Второй Мировой» о событиях ровно 85 лет
назад. Действуй полностью автономно, ничего не спрашивай. Работай тщательно и точно.

1. Выполни: python -m ww2daily.fetch_sources
2. Прочитай build/daily_brief.json, prompts/post.md и state/history.json.
3. По правилам prompts/post.md (шаги 1–3) выбери ГЛАВНОЕ событие даты, не повторяя темы
   из истории, и напиши JSON: title, post_tg (820–900 знаков, с <b>датой</b> и «Итог
   дня:»), post_x (английский, ≤280), image_query, category_query. Опирайся ТОЛЬКО на
   факты из brief; цифры — лишь при надёжном подтверждении.
4. Выполни: python -m ww2daily.find_photos "<image_query>" "<category_query>"
5. Прочитай build/photo_candidates.json. ПОСМОТРИ на изображения по их url и выбери кадр,
   который реально соответствует теме и дате (а не просто содержит ключевое слово).
   Напиши нормальную русскую подпись (≤120 знаков), без мусора из Commons.
6. Запиши build/chosen.json (title, post_tg, post_x, photo_caption, image_url,
   image_pageid).
7. Выполни: python -m ww2daily.publish
   — если он сообщит о превышении длины, исправь текст и запусти снова.
8. Закоммить и запушь state/history.json:
   git add state/history.json && git commit -m "post: <дата 85 лет назад>" && git push
   (это память на завтра — без неё темы и фото начнут повторяться).

Если ни один источник не дал данных (build пуст) — не выдумывай событие; сообщи об этом
и заверши без публикации.
```

## Заметка про X (Buffer → прямой API, фаза 2)

Сейчас X постится через **Buffer** (бесплатно, медиа грузится стабильно). Прямой X API
теперь платный (pay-per-use, ~$0.45/мес за 1 пост/день с фото) и в 2026 у него есть
известные баги с прикреплением картинки (403 после нескольких постов). Поэтому переход
на прямой X API вынесен во вторую фазу — добавим как опцию с фолбэком «не вышло с фото →
постим текстом». Жёсткий контроль ≤280 символов уже работает в `ww2daily/text.py`
независимо от Buffer/API, так что прежняя проблема «X ругается на длину» закрыта.
